## What I learned

- A repository is a permanent record. this record allows you to share an online copy of your code with anyone.
- A README file helps share important information about your project. Such as what it does, why it is useful, and how to get started with it.
- A commit records changes made to one or more files. The commit stores a unique ID in order to identify the exact changes made.
